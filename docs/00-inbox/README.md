# Inbox — received, not yet reviewed

**Put new external material here.** Anything in this folder is treated as
**unreviewed and non-authoritative** until it has been audited against the
canon.

## What goes here

- Feedback on documentation we sent
- New packages or artefacts from the external work front
- Third-party research, datasets, reports

Drop files in as-is. Keep the sender's filenames and any checksum files —
those are how integrity gets verified.

## Lifecycle

```
00-inbox/            received, unreviewed
     ↓  audit against canon; verify claims at source
01-canon/ + 02-workstreams/ + 04-evidence/   accepted corrections applied
     ↓
99-archive/external-packages/   original preserved intact, checksums still valid
```

**Nothing is cited from this folder.** If a claim here survives audit it moves
into canon; the original then moves to the archive so its provenance stays
verifiable.

## Rules

- The inbox is emptied after processing — a permanently full inbox means work is queued, not done.
- Received documents are archived **unmodified**. If a live working copy needs edits (renamed cross-references, appended notes), the copy carries a provenance note and the original stays untouched in the archive.
- Claims are verified at source, not accepted because they are asserted.
