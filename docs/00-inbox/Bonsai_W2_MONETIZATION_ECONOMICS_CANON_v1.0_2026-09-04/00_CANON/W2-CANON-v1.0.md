# 1. Current economic question

> **Can Bonsai reach and retain enough economically eligible payers to clear S1 while beating existing substitutes and keeping acquisition, support and continuity costs sustainable?**

The project has already established that:

- longitudinal recordkeeping exists;
- paid use exists;
- paid persistence exists in individual cases;
- switching/exit exists;
- subscription resistance exists;
- general-purpose and analog substitutes are real;
- logging burden can cause exit.

Therefore W2 is **not** asking whether a recordkeeping job exists.

W2 is asking whether a sufficiently large, sufficiently valuable and sustainably
serviceable subset exists.

# 7. Landing page decision inside W2

W2 supports creating the landing page now under this definition:

> **Landing Page v0 = acquisition + participant recruitment + one-tree commitment instrument.**

It is **not** treated as:

- proof that P1/P2/P3 is selected;
- proof of demand;
- pricing validation;
- production marketing commitment.

Preferred behavioral ladder:

1. visit / scroll — very weak;
2. CTA click — weak;
3. email / early-access signup — acquisition signal;
4. provides real tree context — stronger;
5. starts with one real tree — materially stronger;
6. returns voluntarily — economically relevant;
7. pays after current value — monetization evidence.

W2 recommendation for the first landing:
- do not lead with final pricing;
- do not promise permanent/forever history;
- do not lead with AI advice;
- do not present Comparable Journey as validated;
- use the landing to recruit into Step 1 / one-tree behavior.
