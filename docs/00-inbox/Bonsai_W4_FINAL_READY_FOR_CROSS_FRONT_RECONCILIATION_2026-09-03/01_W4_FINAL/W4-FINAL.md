# 0. Executive conclusion

W4 finds **no validated Growth loop** and does not select P1, P2 or P3. The strongest Growth conclusion is narrower and more useful:

> **The venture must create differentiated current value before migration and repeated logging costs become the dominant experience.**

The leading shared gate is therefore:

> **Can a dedicated one-tree experience generate current, differentiated value over Photos/Excel/notes before the user must migrate a collection or wait for long-history payoff?**

W1, W2, W3 and W4 now converge around a staged hypothesis:

`practical entry / Progress → current organization/retrieval value → Memory → Continuity/trust → Comparable Journey / Learning`

Each arrow remains `UNVALIDATED`. The sequence is a falsification agenda, not a product decision.

W4 recommends carrying **L1–L6** into reconciliation with different dispositions:

- **L2 · One-Tree Land-and-Expand:** primary participant gate.
- **L4 · Comparable Journey:** high-priority cross-front hypothesis, but first gated by corpus density.
- **L3 · Progression Artifact:** primary object-led propagation hypothesis tied to Progress.
- **L1 · First-Tree Inception:** low-migration beginner acquisition/activation hypothesis.
- **L5 · Teacher/Club Continuity:** actor-led distribution hypothesis, gated separately from professional payer discovery.
- **L6 · Transfer/Provenance:** strategic secondary / long-cycle.

No channel plan should be chosen before these mechanisms survive their gates.

# 3. Potential Growth mechanisms

## L1 · First-Tree Inception

`first tree → minimal record → immediate Progress/baseline value → spontaneous return → journey becomes more useful`

- Strength: migration burden near zero.
- W3 permission: Progress + Psychological Safety; “it is legitimate to be learning.”
- Not permitted: unearned expert care, “avoid killing your tree”, AI recommendation authority.
- Main risk: first-tree user primarily needs guidance rather than record/memory.
- Status: `UNVALIDATED`.

## L2 · One-Tree Land-and-Expand

`workflow pain → one real tree enters → differentiated current value → voluntary return → optional second tree / workflow shift`

- Role: activation/expansion prerequisite, not inherently user-to-user acquisition.
- Cross-front role: closest Growth analogue to W2 `G1 Dedicated Advantage + G2 Current Value`.
- Brand rule: if dedicated value does not beat the workaround in favorable conditions, Continuity/Journey/Story must **not** rescue the thesis rhetorically.
- Status: `UNVALIDATED`; **primary participant gate**.

## L3 · Progression Artifact

`fragmented history → coherent progression artifact → owner value → artifact travels naturally → recipient meaningfully activates`

- Brand rule: `progress/story > prestige`; `contribution ≠ invitation for critique`.
- Sharing must not depend on ranking, status, obligation or forced incentive.
- Can survive as owner value while failing as Growth loop.
- Status: progression value supported; propagation `UNVALIDATED`.

## L4 · Comparable Journey

`need/new species/problem → comparable documented journeys → descriptive learning → repeat use and/or contribution → richer corpus`

- Cross-front importance: W2 economic A3 + W3 Journey→Learning + W4 evidence-producing candidate.
- Gate 1: corpus density.
- Brand boundary: “these cases are comparable” is allowed; “therefore do X” crosses into authority-heavy recommendation.
- Main risks: sparse corpus, consumption without contribution, forum/search/expert preference, capture burden.
- Status: `UNVALIDATED`.

## L5 · Teacher / Club Continuity

`session → work/context recorded → same tree returns → next session benefits → actor repeats with future participants/cohorts`

- Separate **distribution actor** from **payer**.
- Authority remains with practitioner/teacher/club/institution; `practitioner-attested` is acceptable, “Bonsai-verified” is not.
- Professional workflow/budget discovery may run early; L5 as Growth loop waits for user-level value.
- Kill if teacher/student becomes a data-entry clerk.
- Status: `UNVALIDATED`.

## L6 · Transfer / Provenance

`steward A → tree + record → steward B → continuation → later transfer`

- Genuine tree-to-person propagation shape.
- Strategic secondary because cycle is slow and requires durable prior history.
- Evidence/attestation describes confidence in a claim, not tree quality/status.
- No pedigree coding, prestige badges, verified-tree status or provenance ranking.
- Status: `UNVALIDATED`.

# 5. Cold-start analysis

These are structural expectations, not validated user-count thresholds.

| Scale | Potential standalone value / mechanism |
|---|---|
| **User 1** | L1/L2 can provide one-tree progress, memory, retrieval if differentiated from workarounds; L3 can create owner artifact value |
| **Small local cohort** | L5 can work with one teacher/club without global network density |
| **~100 relevant records** | limited Comparable Journey matches may begin if cases cluster rather than fragment |
| **~1,000 relevant records** | broader comparison/relationship potential, still highly sensitive to species/context distribution |
| **larger corpus** | structured outcome patterns become conceivable, but inference/authority gates remain separate |

W4 explicitly rejects fixed “100/1,000/10,000” network-effect claims as evidence. Density must be measured against the actual matching dimensions.

# 6. Standalone value before network scale

- **L1:** yes in principle; first-tree baseline/progress can exist alone.
- **L2:** yes in principle; one-tree organization/retrieval can be tested with one user.
- **L3:** owner value can exist before recipient propagation.
- **L4:** weak at user 1; depends on corpus density.
- **L5:** can work inside one actor-led cohort.
- **L6:** low global density requirement but high time/history requirement.

Therefore W4 favors mechanisms whose first value does not require an empty network to magically become lively.

### W3 Brand/message kill conditions now adopted by W4

A mechanism is downgraded or killed if:

**A.** it only works using unearned expert/care authority;  
**B.** it requires status/ranking/prestige to make Progression/Provenance travel;  
**C.** Continuity requires operational claims the venture cannot guarantee;  
**D.** “easy logging” is the only convincing differentiation from Photos/Excel/notes;  
**E.** an artifact travels only through forced/incentivized sharing rather than intrinsic recipient value;  
**F.** Comparable Journey only works when framed as recommendation rather than descriptive learning;  
**G.** practitioner authority must be appropriated by the brand for the mechanism to appear trustworthy.

# 14. Kill conditions / mechanisms not to pursue

## Cross-loop kill rule

> **Do not pursue a mechanism that requires substantial migration/logging work before differentiated value appears.**

## Specific kill/downgrade rules

- **L1:** kill as record-led entry if spontaneous post-session return does not occur or value requires authority-heavy advice.
- **L2:** kill/park dedicated land-and-expand if current value does not beat the substitute or no voluntary return/workflow shift occurs; Brand must not rescue failure with Continuity/Story copy.
- **L3:** downgrade to owner feature if artifact does not travel; kill as Growth loop if it travels but recipients do not activate or travel requires status/forced sharing.
- **L4:** kill if realistic corpus density cannot produce useful matches; downgrade if people consume but never return/contribute; kill Brand-compatible form if value only appears as recommendation.
- **L5:** kill as repeatable distribution if actor will not repeat without founder labor, or if teacher/student becomes a data-entry clerk; professional payer evidence alone does not save the Growth loop.
- **L6:** do not prioritize early if durable history rarely exists by transfer time or recipient continuation is negligible.

Do not pursue as assumed strategies at this stage:

- generic community feed;
- generic referral/“invite friends” mechanics;
- follower/status/ranking-based growth;
- paid acquisition economics;
- SEO/content flywheel;
- nursery monetization;
- “easy logging” as standalone wedge;
- Continuity as an absolute permanence promise.
