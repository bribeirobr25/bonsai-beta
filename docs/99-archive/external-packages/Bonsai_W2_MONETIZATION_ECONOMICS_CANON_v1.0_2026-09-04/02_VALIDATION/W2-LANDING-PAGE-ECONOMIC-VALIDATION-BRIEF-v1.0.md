# Bonsai · W2 · Landing Page Economic Validation Brief v1.0

**Date:** 4 September 2026  
**Status:** ACTIVE W2 VALIDATION INSTRUMENT BRIEF  
**Founder direction:** web app · mobile-first · desktop/tablet friendly  
**Product validation status:** still `UNVALIDATED`

---

# 1. W2 approval

W2 supports creating the landing page now.

But W2 defines its role as:

> **acquisition + participant recruitment + one-tree commitment instrument**

not as:
> final product marketing site.

---

# 2. What the landing should test

## Message / entry
Which credible promise causes qualified attention?

Likely hypotheses:
- Progress as entry;
- Memory / organization / retrieval as current utility bridge.

## Segment
Who responds:
- first/second-tree beginner;
- expanding hobbyist;
- experienced grower;
- practitioner.

## Commitment
Does the visitor move beyond interest and attach a **real tree** to the next step?

---

# 3. Preferred behavioral ladder

| Behavior | W2 interpretation |
|---|---|
| visit / scroll | very weak |
| CTA click | weak |
| email / early-access signup | acquisition signal |
| provides real tree context | stronger |
| starts with one real tree | meaningful commitment |
| returns voluntarily | economic-value signal |
| pays after current value | monetization evidence |

---

# 4. CTA principle

Prefer a CTA direction similar to:

> **Start with one tree**

or:

> **Join early access with one tree**

rather than:
- “Download the app”;
- “Subscribe now”;
- a generic waitlist only.

The exact copy is W3/Product work.

W2's requirement is behavioral:

> the landing should make it possible to recruit or identify a real one-tree commitment.

---

# 5. Pricing rule

W2 recommends **not using final pricing as the primary first landing test**.

Reason:

If conversion is weak, pricing-first cannot distinguish:
- weak value;
- weak message;
- substitute preference;
- price resistance.

Correct sequence:

> value → behavior → payment architecture → price.

A later landing variant may test real-money commitment after G1/G2 survive.

---

# 6. Claims W2 does not authorize

Do not imply:

- “forever”;
- “permanent”;
- “never lose your history”;
- verified provenance;
- AI advisor authority;
- evidence-based horticultural recommendation;
- Comparable Journey as validated;
- professional workflows as validated.

---

# 7. Economic message discipline

Shared cross-front rule:

> **message that acquires ≠ value that retains ≠ value that monetizes**

A plausible hypothesis is:

> Progress attracts  
> Memory / organization / retrieval creates current return  
> Continuity creates trust  
> Comparable Journey may later create recurring differentiation

Do not present this chain as validated.

---

# 8. Measurement requirements

At minimum track:

- landing visits;
- qualified CTA clicks;
- signup;
- participant segment;
- number of trees;
- current tracking workaround;
- real-tree commitment;
- entry into Step 1;
- voluntary return if the validation flow continues.

Do not convert landing conversion into:
- PMF;
- retention;
- WTP;
- market size.

---

# 9. W2 success criterion for the landing itself

The landing succeeds as a **validation instrument** if it:

1. recruits sufficiently qualified participants for Step 1;
2. distinguishes message/segment response;
3. enables a real one-tree commitment;
4. preserves evidence discipline.

It does not need to prove the business on its own.
