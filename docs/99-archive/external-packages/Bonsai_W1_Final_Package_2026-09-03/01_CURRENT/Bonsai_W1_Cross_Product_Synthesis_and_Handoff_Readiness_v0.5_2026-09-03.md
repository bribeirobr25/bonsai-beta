# Bonsai · W1 · Cross-Product Synthesis & Handoff Readiness v0.5

**Date:** 3 September 2026  
**Status:** PRE-VALIDATION / Track A  
**Derived evidence corpus:** 88 units  
**Sampling warning:** the corpus combines calibration, purposive exit/persistence enrichment, storefront reviews and targeted public feedback. It is **not** a probability sample and must not produce market-prevalence percentages.

## Executive conclusion

W1 has now produced enough independent behavioral evidence to improve W2–W4,
but **not enough to choose P1/P2/P3 or declare the record thesis validated**.

The cross-product evidence supports a narrower and more useful statement:

> **A longitudinal record job exists and can sustain months/years of use for
> some growers. Dedicated software loses when its incremental value fails to
> exceed repeated capture cost, collection-scale complexity, subscription
> resistance, reliability/continuity risk and the convenience of general-purpose
> tools.**

Status: `SUPPORTED SIGNAL`, built from multiple `OBSERVED` behaviors.

## 1. What W1 can now state with confidence

### OBSERVED

1. Growers keep bonsai records in multiple forms: dedicated apps, spreadsheets,
   documents, photo albums, notebooks and hybrid systems.
2. Some dedicated-app users continue for months, years or daily use.
3. Some users pay for dedicated tracking.
4. Some users explicitly uninstall, abandon or switch systems.
5. Some users return from dedicated apps to generic tools.
6. Repeated data-entry burden is an explicit abandonment cause.
7. Collection growth creates retrieval/organization pressure.
8. Photo progression is repeatedly valued.
9. Reminders can be useful, but reminder design/context can itself create churn.
10. Data loss, service mortality and export/lock-in affect trust.
11. Dedicated bonsai apps compete directly with general-purpose tools, not only
    with one another.

### SUPPORTED SIGNAL

1. The core tension is **cumulative history value versus repeated maintenance
   cost**.
2. A richer schema can improve retrieval while simultaneously increasing capture
   friction.
3. Beginners and experienced growers have materially different jobs.
4. Long-term trust/data portability may be part of the value proposition, not
   merely infrastructure.
5. Generic care/advice increases the authority burden relative to neutral
   recordkeeping.
6. “Low-friction logging” is not a differentiated wedge by itself because many
   current entrants already position there.

### CONTRADICTED

1. “Nobody sustains bonsai tracking.”
2. “Tracking/care is a sparsely attempted software space.”
3. “Bonsai-specific software competes only with other bonsai apps.”
4. The prior market-scan claim that BonsaiDo was the observed US iOS rating
   leader.
5. The prior ~330 four-market iOS category figure as a reliable category-wide
   total.

### UNVALIDATED

1. What share of growers intentionally keep records.
2. H1B private longitudinal-record prevalence.
3. Six-month+ retention distribution.
4. What share pay.
5. Whether a dedicated record product can beat general tools for a large enough
   segment.
6. Whether provenance/attestation adds meaningful value.
7. Whether Comparable Journey drives repeat use.
8. Whether community improves retention.
9. WTP, unit economics and market ceiling.
10. Which product candidate, if any, should survive cross-front reconciliation.

## 2. The most important contradiction inside the evidence

Two behaviors coexist:

**Persistence**
- daily app use,
- multi-month app use,
- 2+ year paid use,
- subscription since launch.

**Exit / avoidance**
- uninstall next day,
- abandon app for photos/metadata,
- use Excel instead of tracker,
- refuse app due subscription,
- refuse even free app due longevity/lock-in concern.

This is not noise. It indicates likely segment heterogeneity.

The strategic task is therefore **not to average these people together**.

## 3. The central W1 mechanism hypothesis

Working model:

`record pressure / memory pain / progression value / collection complexity`

must exceed:

`capture effort + retrieval effort + subscription + reliability risk + lock-in + good-enough workaround`

for dedicated software to persist.

This is **not a validated equation**. It is the best explanatory hypothesis
currently supported by the review/public-feedback evidence.

## 4. Product-level read

### Bonsai Album
Strongest historical proof that a neutral record/database can retain value.
Also the clearest example of per-tree input, sync and collection-scale friction.

### Bonsai Care App
Strong evidence on both sides: paid/continued value and explicit uninstall back
to generic tools. Shows that guidance/reminders can attract and repel.

### Appy Bonsai
Strong record/collection value signals, but also direct switching and
developer-acknowledged bug/stability churn.

### BonsaiDo
Multi-year paid use is directly observed. A data-loss incident demonstrates the
trust cost of becoming a real system of record.

### Jooni
Progression/community value appears, but bugs and tiny review base limit
conclusions.

### New 2026 entrants
Useful mainly as **competitive positioning evidence**. They repeatedly promise
low friction, privacy/offline, photo timelines, configurable reminders and
history. Most lack mature user evidence.

### General-purpose tools
Must be considered a first-class competitor category.

## 5. Segment read

### First/second tree
Likely jobs visible in current evidence:
- reassurance,
- basic guidance,
- remembering planned care,
- reducing intimidation.

### Expanding hobbyist
- organization,
- collection retrieval,
- batch work,
- photos/history,
- memory relief.

### Experienced / long-horizon
- detailed history,
- experimentation,
- custom rules,
- export/continuity,
- low tolerance for generic advice.

### Low-software / analog
- accepts less structure in exchange for simplicity, durability and lower screen
  burden.

Status for segmentation: `SUPPORTED SIGNAL`.

## 6. W2 handoff

W2 can now treat these as evidence inputs:

- paying users exist;
- subscription rejection also exists;
- free/general tools are the economic substitute;
- long-horizon data continuity creates a business-model tension;
- collection complexity may correlate with greater value;
- Android adoption is broader than previously understood.

W2 must still answer:
> **What value can be monetized repeatedly when the user's alternative costs
> almost nothing?**

## 7. W3 handoff

Credible meaning territories supported by user language:
- memory,
- continuity,
- progression,
- calm organization,
- ownership of one's history,
- “remember what I already know.”

Risky territory:
- expert replacement,
- generic AI authority,
- permanent-record claims without credible export/continuity.

## 8. W4 handoff

Behaviorally supported acquisition moments:
- first tree / intimidation;
- collection outgrows memory;
- spreadsheet/photo workflow becomes cumbersome;
- current tracker fails;
- data/export concern;
- desire to show progression.

Potential traveling objects:
- before/after,
- progression,
- portable/shareable tree history.

## 9. Is W1 ready for handoff?

**Yes, for an interim evidence handoff to W2–W4.**

W1 has enough evidence to constrain their thinking.

**No, W1 is not complete as a behavioral validation programme.**

The remaining high-value work is narrower:
1. build a source-normalized review corpus from the highest-signal products;
2. improve explicit abandonment/persistence evidence without pretending
   prevalence;
3. run or obtain a proper H1A/H1B-compatible study if needed;
4. investigate provenance/transfer reviews specifically;
5. investigate Comparable Journey/community behavior specifically.

## 10. Recommended governance

W2–W4 should receive this interim handoff now rather than waiting for W1 to
become exhaustive.

W1 should continue in parallel, but no longer delay the other fronts merely to
find more variants of the same tracking complaint.

A later W1 amendment should be issued only if new evidence materially changes:
- the persistence-vs-friction model,
- the segment split,
- the market-scan correction,
- or the viability of one of the remaining hypotheses.
