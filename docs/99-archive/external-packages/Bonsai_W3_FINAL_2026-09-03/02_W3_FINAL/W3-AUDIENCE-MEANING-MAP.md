# Bonsai · W3 · Audience Meaning Map v1.0

**Status:** Final W3 working artifact for Cross-Front Reconciliation  
**Date:** 3 September 2026

## 1. Audience model

Use two dimensions:

### Bonsai journey stage
1. zero-knowledge / first-tree beginner
2. first / second-tree owner
3. expanding hobbyist
4. experienced / long-horizon hobbyist

### Software posture overlay
A low-software/analog posture exists across stages. W1 observed use of paper, notebooks, spreadsheets, photo systems, metadata and memory. Prevalence remains `UNVALIDATED`.

Practitioners/teachers are ecosystem/authority actors, not automatically the primary consumer target.

## 2. Map

| Segment | Jobs | Anxieties | Aspirations | Meaning candidates | Evidence caution |
|---|---|---|---|---|---|
| Zero-knowledge / first tree | simple memory, first record, reassurance, progress | killing tree, vocabulary, judgement | feel capable | Progress, Confidence, Memory | provenance/legacy not established |
| First / second tree | tracking, photos, notes, reminders, progress | forgetting, fragmentation, not seeing change | recognize learning | Progress → Memory → Journey | Journey is strategic framing |
| Expanding hobbyist | collection organization, retrieval, batching, history | memory pressure, migration, capture burden | structure without bureaucracy | Memory, Continuity, Progress | dedicated software advantage unvalidated |
| Experienced / long-horizon | detailed history, custom workflows, experiments | data loss, lock-in, software mortality, generic advice | durable controlled record | Continuity, Autonomy, Durable Trust, Living History | not all want specialized software |
| Practitioner / teacher | future attestation/teaching role | reputational/workflow burden | transmit trustworthy context | Stewardship, Trusted contribution | H5/teacher economics unvalidated |
| Low-software overlay | paper/photos/spreadsheets/notes | software overhead, subscription, fragility | control/minimum maintenance | Autonomy, Durable Trust | prevalence unknown |

## 3. Meaning progression hypothesis

W3 strategic interpretation:

> **keep up → see change → remember → preserve continuity**

This is not verbatim customer language.

## 4. Literal customer language boundary

Observed by W1:

`keep track` · `progress` · `reminders` · `my trees` · `collection` · `photos` · `notes` · `organize` · `record` · `one place`

Strategic synthesis, not verbatim:

`memory` · `continuity` · `journey` · `ownership/control of history` · `calm organization` · `long-term memory` · `stewardship`

## 5. Audience implication

Do not design one proposition for every segment. Entry language may be practical while long-term meaning deepens through tenure.
