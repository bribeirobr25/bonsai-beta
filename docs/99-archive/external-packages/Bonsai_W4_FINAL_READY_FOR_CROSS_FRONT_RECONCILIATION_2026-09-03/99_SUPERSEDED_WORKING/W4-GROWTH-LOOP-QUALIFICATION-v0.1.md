# 1. W4 organizing question after W1

> **Which acquisition moment produces differentiated value before migration and repeated logging costs dominate the experience, and can that mechanism also produce evidence or a propagating object?**

W1 strengthens a specific constraint:

> growers can sustain longitudinal records, but dedicated software loses when incremental value does not exceed repeated capture cost, collection-scale complexity, business-model resistance, reliability/continuity risk and the convenience of general-purpose tools.

Therefore W4 must distinguish:

- **entry / switching trigger** — why a person becomes receptive;
- **activation mechanism** — how differentiated value appears;
- **expansion mechanism** — why use broadens from one tree/use case to more;
- **propagation mechanism** — what reaches another person;
- **growth loop** — how the next participant creates new value or evidence that can restart the cycle.

These are not synonyms.

# 5. Cross-loop prerequisite gates

Before calling any mechanism a sustainable Growth loop, W4 should test the relevant gates.

| Gate | Question | Why it matters after W1 |
|---|---|---|
| **G0 · Immediate differentiated value** | Does value appear before the user enters/migrates a collection? | W1 shows delayed history value can lose to immediate capture cost |
| **G1 · Repeat behavior** | Does the user return and record/retrieve something without guided prompting? | persistence exists, but so does abandonment |
| **G2 · Expansion** | Does value from one tree/use case cause voluntary expansion? | full-collection entry can happen, but burden is unmeasured |
| **G3 · Object travel** | Does a Journey/progression/record naturally reach another person? | progression is valued, but product-level propagation is unvalidated |
| **G4 · Recipient activation** | Does the recipient do something meaningful, not merely view? | views/likes are not acquisition |
| **G5 · Actor repetition** | Will a teacher/club/nursery repeat the mechanism with another person? | actor-led distribution is only a loop if the actor has incentive to repeat |
| **G6 · Evidence quality** | Does growth create usable behavioral/provenance/comparison evidence? | evidence-producing loops are strategically superior in pre-validation |
| **G7 · Economic viability** | Can W2 economics support the actor and acquisition cost? | free/general tools and subscription rejection are real competitors |
| **G8 · Brand/trust permission** | Can W3 credibly frame the value without unearned expertise or durability promises? | system-of-record claims raise trust and continuity expectations |

# 6. Candidate Loop Cards

## L1 · First-Tree Inception

**Class:** acquisition + activation; actor-assisted propagation possible  
**Status:** `UNVALIDATED` loop built on supported first-tree jobs

**Flow**  
`first tree / intimidation → teacher/workshop/nursery moment → create minimal tree baseline → immediate memory/progression value → first real event occurs → user returns → journey begins → actor repeats with another beginner`

**Behavioral basis**
- first/second-tree reassurance and easy first record are supported jobs;
- beginner public exposure can be intimidating;
- workshop cohort exists as an optional validation channel.

**Why it matters**
- migration burden is almost zero: the tree has little or no prior digital history;
- can test whether a record creates value before historical accumulation.

**Evidence produced**
- guided creation versus spontaneous later return;
- 7/14/30-day behavior in the workshop context, with the canon's generalization limits;
- first events users choose to record;
- whether the actor needs to prompt every return.

**Dependencies**
- W3: reassurance/record framing without pretending to be an expert advisor;
- W2: nursery/teacher economics if actor-led distribution becomes central.

**Kill conditions**
- value exists only while instructor/actor is present;
- after first creation, users do not independently return for record/progression value;
- the segment primarily demands authority-heavy advice and treats recordkeeping as extra work.

**W4 disposition:** **advance to falsification design**.

---

## L2 · One-Tree Land-and-Expand

**Class:** activation/expansion loop; **not a user-to-user acquisition loop**  
**Status:** `UNVALIDATED` mechanism directly addressing W1's strongest activation risk

**Flow**  
`collection pressure / cumbersome tool / tracker failure → enter or import one tree → differentiated value appears → user voluntarily adds a second/third tree → system captures larger share of collection`

**Behavioral basis**
- collection pressure, general-tool substitution, app switching and full-collection entry are `OBSERVED`;
- repeated capture cost versus cumulative value is a `SUPPORTED SIGNAL`.

**Why it matters**
This is a prerequisite test for any Growth strategy aimed at existing growers. If a user must migrate 20–30 trees before understanding the value, acquisition can fail before activation.

**Evidence produced**
- time-to-value with one tree;
- voluntary 1→2→N expansion;
- which value causes expansion: retrieval, progression, organization, continuity, something else;
- migration effort and abandonment behavior.

**Dependencies**
- W2: incremental value must justify switching/business-model cost;
- W3: dedicated value must be explainable without saying merely “easier logging.”

**Kill conditions**
- users cannot perceive differentiated value until most of the collection is migrated;
- one-tree use adds no meaningful value over Photos/notes/spreadsheet;
- voluntary expansion does not occur without heavy prompting.

**W4 disposition:** **advance as a mandatory activation prerequisite**, not as evidence of virality.

---

## L3 · Progression Artifact

**Class:** value + propagation candidate  
**Status:** progression value `OBSERVED`; propagation/conversion `UNVALIDATED`

**Flow**  
`fragmented photos / desire to see development → coherent progression artifact → owner receives immediate reflection/value → artifact is shared/discovered → another grower follows/opens it → recipient starts or follows a relevant journey → more progression material exists`

**Behavioral basis**
- photo/progression value is robust across products and general-tool workflows;
- people ask to keep following specific trees;
- conversation-centric systems can fragment a tree's history.

**Why it matters**
This is one of the few candidate objects with an already-observed reason to exist independently of Growth.

**Evidence produced**
- whether owners create/reconstruct the artifact voluntarily;
- whether they share it without Growth prompting;
- what viewers do after encountering it;
- whether tree-specific following produces repeat non-owner interaction.

**Dependencies**
- W3: progression/story framing;
- possible W2 dependence if public artifacts require free access to propagate.

**Kill conditions**
- coherent progression is not materially better than Photos/Lightroom for owners;
- users value progression privately but do not let the object travel;
- viewers consume without any meaningful follow/create/return behavior.

**W4 disposition:** **advance to a cheap object-propagation test**.

---

## L4 · Comparable Journey Contribution

**Class:** discovery → learning → contribution loop  
**Status:** public progression as learning infrastructure `OBSERVED`; H6B/product mechanism `UNVALIDATED`

**Flow**  
`new species / problem / intervention decision → user sees structurally similar documented journeys → learns without direct recommendation → records own event/context/outcome → corpus gains another comparable case → future users find better matches`

**Behavioral basis**
- growers use progression threads as learning infrastructure;
- Comparable Journey itself is explicitly unvalidated;
- levels 0–3 of the advice ladder avoid authority-heavy recommendations.

**Why it matters**
Potentially turns acquisition and use into evidence production rather than merely traffic.

**Evidence produced**
- which dimensions users actually require for “comparable”: species, climate, stage, intervention, state, other;
- whether a case without recommendation is useful;
- whether usefulness causes contribution;
- corpus-density requirements.

**Dependencies**
- sufficient structured histories;
- domain model can represent context, state, intent, outcome and uncertainty;
- W3 must not frame retrieval as expert advice.

**Kill conditions**
- users prefer a direct expert answer and find comparable cases insufficient;
- useful matches require such narrow context that corpus density is impractical;
- consumers benefit from cases but do not contribute usable records/outcomes.

**W4 disposition:** **advance only as a manual/concierge value+density test**, not as a network claim.

---

## L5 · Teacher / Club Continuity

**Class:** actor-led acquisition + repeat-use + possible cohort propagation  
**Status:** recurring small-group learning `OBSERVED`; distribution willingness/economics `UNVALIDATED`

**Flow**  
`teacher/club session → intervention or state recorded on same tree → student carries context between sessions → next session uses accumulated journey → teacher/club repeats system with other learners → records/attestations accumulate`

**Behavioral basis**
- recurring study-group learning exists, including multi-year participation;
- practitioner authority is structurally valuable;
- P3 remains an unvalidated candidate, not a chosen product.

**Why it matters**
One mechanism could simultaneously test distribution, repeat usage, teacher friction, student logging and attestation behavior.

**Evidence produced**
- actor willingness to initiate/repeat;
- student behavior between sessions;
- whether longitudinal context improves the next interaction;
- practitioner attestation friction;
- whether actor-led acquisition survives outside one workshop.

**Dependencies**
- W2: teacher/club economics and viable sales/distribution model;
- W3: role of practitioner authority and brand boundaries;
- operational burden must be extremely low.

**Kill conditions**
- teachers/clubs experience the system as extra administration;
- students do not maintain useful context between sessions;
- the actor has no reason to repeat the mechanism with future learners;
- W2 shows acquisition/sales cost incompatible with market ceiling.

**W4 disposition:** **advance to actor/concierge falsification; hold economic conclusion for W2 reconciliation**.

---

## L6 · Transfer / Provenance

**Class:** tree-to-person propagation  
**Status:** provenance weight `OBSERVED`; transfer exists competitively; verifiable-provenance value H5 `UNVALIDATED`

**Flow**  
`tree sale/gift/inheritance → current steward passes history with tree → recipient receives immediate context → recipient continues journey → future transfer carries richer record`

**Behavioral basis**
- provenance has cultural/market precedent;
- ownership transfer/history already exists in competitors;
- stronger `claim → evidence → attestation → confidence` value remains unvalidated.

**Why it matters**
The tree itself becomes the acquisition carrier; network density is not required.

**Evidence produced**
- what history senders actually choose to transmit;
- whether recipients use/continue it;
- whether evidence/attestation changes trust;
- transfer-driven activation.

**Dependencies**
- prior history must exist;
- H5 participant validation;
- W3: provenance without elitism/status coding;
- W2: value capture may be episodic and slow.

**Kill conditions**
- relevant transfers are too infrequent for a primary Growth engine;
- senders do not maintain enough history beforehand;
- recipients do not value continuity;
- simple PDF/paper/export is sufficient and no recurring product relationship follows.

**W4 disposition:** **retain as strategic secondary loop; do not make it the primary early Growth engine**.

# 9. Cold-Start and Scale Read v0.1

The following is a **structural W4 inference**, not an empirical user-count threshold. The numbers are scale thought experiments only; they must not be treated as validated density requirements.

| Candidate | User 1 / one cohort | ~100 relevant users | ~1,000 relevant users | Primary density risk |
|---|---|---|---|---|
| **L1 First-Tree Inception** | can deliver one-tree memory/progression if that value is real | actor repetition can be tested | broader actor distribution might emerge | low network dependency; high repeat-logging dependency |
| **L2 Land-and-Expand** | fully testable with one user and one tree | collection-expansion patterns become measurable | segment-level switching patterns may emerge | essentially no network dependency |
| **L3 Progression Artifact** | owner value can exist alone | some object discovery/follow behavior can be tested | richer discovery graph possible | moderate dependency on viewers/creators, not on dense matching |
| **L4 Comparable Journey** | curated/manual match only | narrow species/context clusters may become viable | meaningful matching may emerge in concentrated segments | **highest density risk** because comparability fragments the corpus |
| **L5 Teacher/Club Continuity** | valuable inside a single teacher/cohort if the workflow works | repeat cohorts/actors can be compared | distribution through multiple actors could emerge | low global density need; local cohort density sufficient |
| **L6 Transfer/Provenance** | can create recipient value with one real transfer | more transfer cases improve evidence, not necessarily utility | network of stewardship histories may emerge | low network density, **high time/history dependency** |

**Cold-start implication:** W4 should favor early tests whose value survives near-zero network density. L1, L2 and L5 are strongest structurally on that dimension. L3 can also create owner value before propagation. L4 must prove that realistic corpus density is enough. L6 does not need density but needs time and prior recording.

# 13. W3 dependencies to reconcile later

W4 needs W3 to determine whether the venture can credibly frame:

1. recordkeeping as **progress / memory / organization** rather than bureaucracy;
2. continuity/durability without making guarantees the venture cannot support;
3. beginner reassurance without claiming practitioner authority;
4. progression/story as a reason to create or share an artifact;
5. provenance without turning evidence into prestige/status hierarchy;
6. teacher/practitioner authority without making the product itself the expert;
7. why a dedicated system is meaningfully different from Photos/Excel without relying on generic “easy logging” claims.

# 14. Kill conditions across W4

W4 should recommend against mechanisms when evidence shows any of the following:

- meaningful value appears only after bulk migration;
- repeated capture burden exceeds the value users actually retrieve;
- a general-purpose tool performs the same job with no meaningful disadvantage;
- propagation produces views but no follow/create/return behavior;
- Comparable Journey requires network density too high for the addressable market;
- actor-led distribution creates more work than value for the actor;
- teacher/nursery/club willingness exists only under subsidized/manual conditions that W2 cannot support;
- transfer is too rare to function as an acquisition engine;
- the system needs authority-heavy recommendations to activate beginners before H7 is resolved;
- a loop depends on generic community participation that has not been demonstrated.

Negative evidence should kill the loop rather than be repaired by adding channels.

# 15. W4 decision after Loop Qualification v0.1

The immediate next work should **not** be channel strategy.

The qualification exercise reduces W4's next falsification agenda to five questions:

1. **Can one-tree use produce differentiated value before migration?**
2. **Does that value cause spontaneous repeat behavior or voluntary collection expansion?**
3. **Can a progression artifact travel and cause a meaningful recipient action?**
4. **Can Comparable Journey create useful learning and contribution at realistic corpus density?**
5. **Will a teacher/club repeat an actor-led mechanism without becoming an unpaid data-entry operator?**

L6 Transfer/Provenance remains strategically relevant but is not the first falsification priority because the cycle is slower and depends on durable history already existing.

**`W4-LOOP-FALSIFICATION-DESIGN-v0.1`** should specify the smallest non-product test for L1–L5, including:

- hypothesis;
- smallest instrument;
- participant/actor context;
- behavior measured;
- evidence generated;
- confounds;
- explicit non-generalization boundary;
- success / mixed / kill interpretation without post-hoc threshold invention;
