### What is genuinely positive

Real progression writing contains much of the structure required for comparison. The domain model is not obviously imposing fields the source material never contains.

### What remains dangerous

`state`, `outcome` and `intent` are only present in 58% of cases. Those are exactly the dimensions that help distinguish “similar story” from “usefully comparable case”.

## Extension design

### Hypothesis

A multi-source, multi-climate corpus contains enough overlap on:

`species × climate × stage/state × intervention`

to return useful comparable cases without collapsing into generic similarity.

### Minimum target

- 20–30 total cases;
- ≥3 independent authors or a genuinely multi-author source;
- ≥3 climate contexts where feasible;
- no one species >50% if source access permits;
- missing fields remain unknown, never inferred.

### Source priority

1. permitted browser-driven access to Bonsai Nut progression threads;
2. otherwise 2–3 independent progression sources in materially different climates;
3. public sources only, limitations documented.

### Extension verdict options

- `SUPPORTED SIGNAL · DENSITY PLAUSIBLE`
- `MIXED · DENSITY FRAGILE`
- `CONTRADICTED FOR CURRENT MATCHING MODEL`

These describe the matching corpus only. They do not validate user utility or Growth.
