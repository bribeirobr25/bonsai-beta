## Standing W4 rules

1. Loops before channels.
2. Acquisition is not activation.
3. Sharing is not propagation.
4. Actor existence is not distribution willingness.
5. Distribution willingness is not payer willingness.
6. Distribution advantage is not retained differentiated value.
7. Manual/concierge labour is a cost.
8. Recruitment source is not Growth evidence by itself.
9. Workshop activation is not organic Growth validation.
10. Do not select geography without loop-specific evidence.
11. Do not let S3 rescue a mechanism that fails S1.
12. Do not run L4-B before density materially improves.
13. Do not let Brand language rescue a failed L2 mechanism.
14. Do not infer network effects from object travel.
15. Preserve message → initial value → return/expansion → monetization as separate mechanisms.
