# Bonsai · W3 · Audience Meaning Map v1.3

**Status:** Canonical W3 strategy artifact  
**Date:** 4 September 2026

## 1. Audience model

Use two dimensions.

### Bonsai journey stage
1. zero-knowledge / first-tree beginner
2. first / second-tree owner
3. expanding hobbyist
4. experienced / long-horizon hobbyist

### Software posture overlay
A low-software / analog posture exists across stages. W1 observed paper, notebooks, spreadsheets, photo systems, metadata and memory. Prevalence remains `UNVALIDATED`.

Practitioners / teachers / clubs / institutions are ecosystem and authority actors, not automatically the primary consumer target.

|---|---|---|---|---|---|
| Zero-knowledge / first tree | simple first record, reminders, progress, reassurance | killing tree, vocabulary, judgement, not knowing what matters | feel capable enough to continue | Progress, Psychological Safety, Memory | provenance/legacy/long-horizon continuity not established |

## 3. Meaning progression hypothesis

W3 strategic interpretation:

> **keep up → see change → remember → preserve continuity**

This is not verbatim customer language.

## 5. Key segment distinction

W3 does not assume one proposition serves all stages.

Possible evolution:

- beginner: **help me keep up / see progress**
- early owner: **help me remember and understand change**
- expanding hobbyist: **help me retrieve and make sense of a growing collection**
- long-horizon owner: **do not let valuable history become fragmented, trapped or lost**

The progression is a Brand hypothesis, not a validated lifecycle funnel.
