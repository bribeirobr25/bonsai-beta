# Bonsai · W3 · Handoff to MVP Validation Strategy v1.0

**Date:** 4 September 2026

## 1. What Brand hands forward

### Target-user discipline

Do not assume one proposition serves first-tree, expanding and experienced growers equally.

### Leading Brand architecture

> **Progress → Memory → Continuity**

### Gated differentiation

> **Journey → Learning / Comparable Journey**

Current L4 structural status: `MIXED · DENSITY RISK HIGH`.

### Core principles

- Psychological Safety
- Durable Trust / User-Controlled History
- authority attribution
- progress/story > prestige
- contribution ≠ invitation for critique
- preserve uncertainty

## 2. What the MVP strategy must prove before Brand deepens

### Primary shared gate

> Can one real tree create current differentiated value over Photos / Excel / notes before collection migration or long historical accumulation?

If no, W3 must downgrade/reopen `Memory → Continuity` rather than rescue it rhetorically.

### Comparable Journey

Before message/utility validation assumes the mechanic works, structural density must be demonstrated across multiple authors/climates.

### Continuity

Before externalizing a strong Continuity promise, the eventual economic/operating model must be capable of truthfully funding the implied obligation.

## 3. Messaging controls for validation

Keep test conditions explicit about whether they are testing:

- acquisition/message relevance;
- activation/current value;
- return/expansion;
- payment;
- deeper Brand meaning.

Never report one as proof of another.

## 4. Validation Landing Page

W3 authorizes a landing-page instrument under `W3-VALIDATION-LANDING-PAGE-BRAND-BRIEF-v0.1.md`.

The page may present a mobile-first responsive web-app concept, but must not imply that the final product or MVP has been selected.

## 5. What Product/UI must not infer from Brand

Do not infer that W3 selected:

- a timeline feature set;
- a database schema;
- export architecture;
- Comparable Journey implementation;
- community;
- AI;
- notifications;
- pricing;
- authentication;
- native versus web technology beyond the founder's current presentation context for the validation landing page.

W3 provides meaning/promise constraints, not product scope.
