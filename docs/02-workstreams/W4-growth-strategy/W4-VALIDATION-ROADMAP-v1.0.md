# W4 · Validation and Falsification Roadmap v1.0

## Sequence

### Step 0 · L4-A Corpus Density — first run complete

Result: `MIXED · DENSITY RISK HIGH`.

**Next Track A work:** extension with multi-source/multi-climate corpus.

### Step 1 · L2 One-Tree Dedicated Value — primary participant gate

Core question:

> Can one real tree produce differentiated current value before migration/history accumulation?

#### W4 F0 existence screen

- 0/8 target behaviours → kill/park;
- 1/8 → mixed;
- ≥2/8 → survives cheap falsification.

F0 does not validate economics.

#### F1 with W2

Before execution, align:

- pain-qualified cohort;
- observation window;
- prompting rules;
- definition of meaningful workflow shift;
- evidence capture.

Current W2 STRONG rules:

- G1: ≥50% continue without prompting AND ≥30% make meaningful real workflow shift.
- G2: ≥50% experience meaningful differentiated current value within 7 days AND ≥40% voluntarily return before long-history payoff.

### Step 2 · L1 First-Tree Inception

Test a simple one-tree start under Progress + Psychological Safety without expert-care claims.

Primary endpoint: spontaneous post-inception behaviour, not guided creation.

### Step 3 · Professional workflow/budget discovery

W2 G7A/B can run early as an S3-route probe. Do not call this L5 Growth validation.

### Step 4 · L3 Progression Artifact

Test:

`owner value → natural travel → recipient activation`

Measure meaningful action. Likes/views are insufficient.

### Step 5 · L4-B Comparable Journey Utility

Only after L4-A extension makes density structurally plausible enough to expose to participants.

Test separately:

- usefulness;
- repeat use;
- contribution after consumption;
- whether descriptive learning works without recommendation.

### Step 6 · L5 Teacher/Club Continuity

Requires:

- user-level value survives;
- actor has a reason/budget or clear non-monetary incentive;
- burden stays below actor-declared tolerance;
- authority remains with actor.

### Step 7 · L6 Transfer/Provenance

Narrow, long-cycle test after a credible recording substrate exists.

## Parallel landing-page validation

Landing page may run before participant product testing as an **acquisition/message instrument**.

It should recruit into actual behaviour when possible. Its data must not be promoted beyond what the action proves.

## Decision discipline

A negative result at L2 is disproportionately important. If L2 fails under favourable conditions:

- park/reframe consumer dedicated-record Growth;
- do not scale acquisition;
- do not use Continuity/Journey/Story to rescue the proposition;
- re-evaluate what, if anything, remains worth testing.
