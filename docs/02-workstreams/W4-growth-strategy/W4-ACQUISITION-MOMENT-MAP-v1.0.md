# W4 · Acquisition Moment Map v1.0

## Purpose

Separate actual behavioural entry/switching pressure from commitment gates, value moments and activation constraints.

| Moment / behaviour | Status of underlying signal | W4 classification | Candidate mechanism | What still needs testing |
|---|---|---|---|---|
| First-tree intimidation | `OBSERVED` / supported beginner friction | entry context | L1 | whether record/progress creates spontaneous return |
| Collection outgrows memory | `OBSERVED` | switching/expansion trigger | L2 | dedicated advantage vs substitute |
| Spreadsheet/notes cumbersome | `OBSERVED` with counter-behaviour | switching trigger | L2 | real workflow shift, not mere preference |
| Fragmented photo history | `OBSERVED` | entry/value trigger | L3 | owner value → travel → recipient action |
| Existing tracker fails | `OBSERVED` | switching trigger | L2 / rescue-entry variants | whether new dedicated value beats general tools |
| Desire to see progression | `OBSERVED` | activation/value moment | L3 / landing Progress framing | whether this generates behavioural next step |
| New species / care problem / intervention | `SUPPORTED SIGNAL` as learning moment | discovery/learning context | L4 | density + actual utility |
| Recurring class/study session | `OBSERVED` context | actor-led recurring moment | L5 | burden, repetition, payer separation |
| Sale/gift/transfer | `OBSERVED` as provenance context | stewardship transition | L6 | recipient activation and cycle frequency |
| Export/data continuity concern | `OBSERVED` concern | **commitment/trust gate** | cross-loop | whether portability changes commitment |
| Migration/repeated logging burden | materially supported | **activation constraint** | cross-loop | actual abandonment/tolerance |

## Excluded from “validated acquisition”

These remain hypotheses, not validated channels/loops:

- nursery visit;
- workshop;
- creators;
- SEO search intent;
- social sharing;
- paid acquisition;
- referral incentives.

They may become useful only when tied to a surviving moment/mechanism and measured behaviour.
