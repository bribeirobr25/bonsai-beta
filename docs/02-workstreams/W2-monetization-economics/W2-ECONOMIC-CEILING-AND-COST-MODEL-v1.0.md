# 5. Long-horizon economics

Raw commodity storage alone is not currently the main existential concern for ordinary record usage.

The structural issue is:

> **revenue duration vs service-obligation duration**

A one-time customer can create years of:
- hosted data;
- backup;
- recovery;
- export;
- migration;
- support.

A subscription funds recurring obligation more naturally but can create:
> “renting access to my own history”

as a trust/demand problem.

No architecture is selected.

Current Apple standalone sample:

- 16/23 zero ratings;
- top 3 = 96% of ratings;
- 20/23 updated in 2026.

Therefore W2 adds:

> **attention/discoverability must enter future CAC/payback analysis explicitly.**

A niche category is not automatically cheap to acquire.

---

# 7. Landing-page economics

The landing page should initially optimize for:

> **qualified one-tree commitment**

not:
> cheap email volume.

A landing that generates many signups but few real-tree starts may pass an acquisition-message test and fail the economic-value bridge.

Founder/manual onboarding time must be costed when evaluating any concierge-assisted conversion.
